# Feirão do Livro

O aplicativo será desenvolvido em React Native utilizando Expo, seguindo o desenho apresentado pelo cliente.

O aplicativo terá quatro telas principais:

* **Inicio**
* **ComoParticipar**
* **Acervo**
* **DetalheLivro**

Na tela **Inicio**, haverá as opções **Ver acervo** e **Como participar**.

Ao tocar em **Ver acervo**, o usuário será levado para a tela **Acervo**, onde serão apresentados livros fictícios. Ao tocar em um dos livros, o aplicativo abrirá a tela **DetalheLivro**, mostrando as informações do livro selecionado.

Na tela **ComoParticipar**, serão apresentadas as informações sobre como participar do Feirão do Livro.

Todas as telas, com exceção da tela inicial, terão uma opção para **Voltar**, permitindo que o usuário retorne à tela anterior.

A navegação será funcional e seguirá o fluxo apresentado no desenho do cliente. Os livros serão fictícios inicialmente, utilizando dados de exemplo.

O projeto será executado pelo **Expo** e testado em um celular para garantir que todos os botões e caminhos funcionem corretamente.

**Fluxo do aplicativo:**

`Inicio → Acervo → DetalheLivro`

`Inicio → ComoParticipar`

`DetalheLivro → Voltar`

`Acervo → Voltar`

`ComoParticipar → Voltar`
